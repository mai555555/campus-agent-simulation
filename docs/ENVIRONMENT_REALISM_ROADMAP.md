# 校园真实环境模拟路线图

## 文档目的

本文记录校园 Agent 平行世界在“真实世界模拟”层面还缺什么，以及这些能力应该按什么顺序进入工程实现。

它不是具体接口文档，也不是一次性实现清单，而是后续拆分 PR、评估模拟真实感、检查 world runtime 迭代方向的共同依据。

## 当前判断

当前系统已经具备校园空间、天气、时间、拥挤度、开放状态、Agent 目标、记忆、关系、行动日志和 world runtime。

但环境层仍偏向“状态标签”和“叙事输入”。要更接近真实校园，环境需要从背景信息升级为可以限制、延迟、改变和反馈 Agent 行动的系统。

核心原则是：

```text
真实环境不是描述词，而是机会结构。
它决定 Agent 能看到什么、能到哪里、要花多少成本、会遇到谁，以及行动失败或偏离的原因。
```

## 第一优先级

第一阶段应优先补齐能立刻改变 Agent 行为质量的基础约束。

### 1. 空间真实约束

当前空间有地点、开放状态和拥挤度，但还需要更细的可计算约束：

- 容量上限与实际占用。
- 排队、等待和满员拒绝。
- 空间之间的距离、移动时间和通行成本。
- 门禁、楼层、入口、开放时间和临时维护。
- 座位、设备、窗口、打印机、实验室名额等资源。
- 噪音、光照、温度、天气暴露和网络状态。

验收标准：

- 空间能够拒绝、延迟或改变 Agent 的行动。
- Agent 的路径、等待、迟到、换地点有明确环境原因。
- 日报和事件流能看到由空间约束引发的异常、聚集和迁移。

### 2. 时间制度

真实校园由时间制度组织。world runtime 已有 day、slot 和 tick，但还需要更细的制度节律：

- 课表、上课铃、下课流动和考试周。
- 饭点、宿舍门禁、图书馆闭馆和校务窗口时间。
- 社团活动、讲座、值班、会议和临时通知。
- 周内/周末、学期阶段、假期和毕业季压力。

验收标准：

- Agent 不只是“随机去图书馆”，而是在制度时间里选择行动。
- 晚到、请假、错峰、赶路、等待等行为自然出现。
- 同一空间在不同时段表现出不同社会功能。

### 3. 个体身体状态

真实人会被身体状态限制。Agent 需要持续变化的内部状态，而不是只按目标行动：

- 饥饿、疲劳、睡眠、健康和体力。
- 压力、情绪、注意力和社交能量。
- 恢复机制：吃饭、休息、睡觉、运动、独处、倾诉。
- 状态累积：长期睡眠不足、考试压力、关系冲突会改变后续选择。

验收标准：

- Agent 会因为疲劳、饥饿、压力而改变计划。
- 行动有成本，恢复有时间，不能无限连续高强度行动。
- 个人生命历程能看到状态积累造成的长期轨迹。

## 第二优先级

第二阶段应强化环境和社会过程之间的闭环，让“新闻价值”和“涌现事件”自然出现。

### 4. 资源流动与稀缺

真实校园中的行为经常被资源驱动：

- 饭、座位、钱、设备、打印名额、实验室资源。
- 课程名额、社团预算、奖学金、实习机会。
- 信息资源：谁先知道消息，谁能接触到机会。

验收标准：

- 资源不足会造成排队、竞争、合作、冲突或替代行动。
- 资源变化会影响关系、目标进度和校园情绪。
- 资源事件能进入日报，而不是只作为后台数值存在。

### 5. 社会传播

当前已有关系和外部资讯，但传播机制还应更真实：

- 八卦、谣言、误读、失真和澄清。
- 信息沿朋友、组织、同空间接触和共同任务传播。
- 权威公告、社交媒体、社团群聊和线下口耳相传。
- 群体情绪、模仿、分化和动员。

验收标准：

- 不同 Agent 对同一事件知道得不同、理解得不同。
- 传播路径可追踪，能看到最早接触者和扩散过程。
- 关系风向、异常内容和群体现象能从传播中涌现。

### 6. 因果反馈

环境变化必须反过来影响行动，行动又继续改变环境：

- 食堂拥挤导致迟到，迟到影响老师评价和压力。
- 暴雨减少操场活动，提高宿舍和图书馆占用。
- 网络故障影响课程、项目、情绪和求助行为。
- 冲突事件改变空间氛围、关系网络和后续避让。

验收标准：

- 事件流能串起“环境变化 -> 行动偏离 -> 关系/记忆/目标变化”。
- world runtime 不只是记录事件，而是让事件影响下一轮 tick。
- 生命周期视图能解释关键转折点的环境原因。

## 第三优先级

第三阶段补齐更完整的社会系统和长期世界感。

### 7. 制度与角色权力

不同角色拥有不同权限和约束：

- 老师、学生、社团干部、宿管、保安、管理员。
- 请假、审批、处罚、奖励、借用空间、发布公告。
- 规则意识、制度信任、申诉和绕行。

验收标准：

- 同一行动对不同角色有不同可行性和后果。
- admin 干预、校方公告和制度事件能与自然演化区分。
- 权力关系能进入关系网络和个人记忆。

### 8. 异常与外部冲击

真实世界需要低频但高影响的扰动：

- 暴雨、停电、网络故障、设备损坏、食堂断供。
- 考试延期、临时讲座、校园冲突、安全事件。
- 外部新闻、就业市场变化、公共卫生或城市事件。

验收标准：

- 外部冲击会改变空间热度、计划、关系和日报。
- 异常不是纯文本，而是会改变后续可行动作和环境状态。
- 系统能记录冲击来源、影响范围和恢复过程。

### 9. 长期人生轨迹

真实世界模拟不只看一天，还应看数周到数月：

- 长期习惯、信誉、社会位置和目标转变。
- 高光事件、失败经验、关系修复和路径依赖。
- 课程、项目、社团、实习、毕业压力等阶段性轨迹。

验收标准：

- 生命历程不是事件列表，而能呈现阶段、转折和后果。
- 长期目标会被环境、关系、资源和制度持续塑形。
- Agent 的选择能表现出人格连续性，而不是每天重置。

### 10. 有限可观测性

真实世界不是全知的。Agent 和观察者都应有观察边界：

- Agent 只能知道自己看见、听见、被告知或推断的事。
- 观察者只影响其关注范围，不应天然获得所有内部状态。
- 信息应有置信度、来源、时间和可能误差。

验收标准：

- Agent 决策上下文与真实数据库状态分离。
- 同一事件可以产生不同主观解释。
- 研究导出能区分“真实发生”和“某个 Agent 以为发生”。

## 推荐实施顺序

```text
阶段 1：空间约束 + 时间制度 + 身体状态
阶段 2：资源稀缺 + 社会传播 + 因果反馈
阶段 3：制度权力 + 外部冲击 + 长期轨迹 + 有限可观测性
```

阶段 1 让 Agent 真正在环境里生活。

阶段 2 让日报、八卦、异常和群体现象从世界运行中自然出现。

阶段 3 让校园从日常模拟升级为更完整的社会系统和研究沙盘。

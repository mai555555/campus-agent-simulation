# 校园真实环境与开放世界模拟路线图

## 文档目的

本文记录校园 Agent 平行世界在“真实世界模拟”层面还缺什么，以及这些能力应以什么依赖顺序进入工程实现。

它不是具体接口文档，也不是一次性功能清单。它用于：

- 指导后续 PR 和数据模型拆分。
- 判断某项能力是否真的提高了模拟真实性。
- 支持从单一校园模拟器走向可配置、可复现的环境生成器。
- 为心理学、传播学、经济学、组织研究和社会科学实验提供共同底座。

## 目标升级

当前系统已经具备校园空间、天气、时间、拥挤度、Agent 目标、记忆、关系、行动日志、简单交易和 world runtime。

但环境层仍偏向“状态标签、叙事输入和单次动作结果”。真实世界不只是更多背景描述，而是由约束、稀缺、信息差、制度、交换和长期反馈共同组成的机会结构。

```text
真实环境
= 可行动机会
+ 行动约束
+ 时间与资源成本
+ 不完全信息
+ 制度和权力
+ 经济交换
+ 直接与延迟后果
+ 可校准的群体结果
```

最终目标不应只是建设一个越来越复杂的校园，而应形成：

```text
可配置环境
→ 可执行因果规则
→ 异质 Agent 行动
→ 多尺度世界反馈
→ 可复现与可比较实验
```

## 当前能力边界

当前已有 `residents.money`、`inventory`、`transactions` 和 `buy_sell`，但它们主要支持固定参数下的余额与库存转移。

这还不能称为经济系统，因为尚未形成：

- 稳定的收入与支出来源。
- 生产、服务供给和库存补充过程。
- 由供需、成本和制度共同形成的价格。
- 劳动、工资、奖学金、租金、税费、补贴和信用。
- 储蓄、借贷、风险和跨期选择。
- 经济不平等、机会差异和阶层流动。
- 可核对的资金、商品与资源流量守恒。

因此，当前系统可以表达“某人花了多少钱”，但还不能解释价格为什么变化、收入从哪里来、谁承担成本、稀缺如何传导，以及政策为什么会产生不同群体后果。

## 设计原则

### 1. 机制优先于叙事

日报、日记和 LLM 文案只能解释已经发生的世界变化，不能代替底层规则。

### 2. 客观世界、可观察世界和主观世界分离

```text
objective_world_state
世界实际发生了什么

observable_state
某个 Agent 此刻能够看到什么

subjective_belief_state
该 Agent 认为发生了什么
```

任何决策、传播、误解和记忆都必须明确使用哪一层状态。

### 3. 存量、流量和事件分离

- 存量：余额、库存、健康、信誉、知识和关系。
- 流量：收入、消费、补货、人流、信息扩散和状态恢复。
- 事件：交易、冲击、审批、违约、关系变化和政策调整。

不能只保存最终余额而丢失产生余额变化的过程。

### 4. 短期、中期和长期机制使用不同节律

- 身体状态和移动可以每个 tick 更新。
- 价格、关系和组织决策可以按小时或天更新。
- 工资、预算和课程结果可以按周或月更新。
- 人口、制度和市场结构可以按学期更新。

### 5. 随机性必须可复现

环境配置、规则版本、模型版本、随机种子、外部数据快照和干预记录必须进入实验元数据。

## 阶段 0：环境生成与因果底座

这一阶段不一定直接增加视觉细节，但决定后续能力会不会成为互不相连的标签。

实施状态（第一批基础设施）：

- 已完成：版本化环境配置、runtime 绑定、配置校验与空间/环境基线应用。
- 已完成：world event 的来源、父事件、根事件和规则版本谱系。
- 已完成：包含客观状态、配置版本、随机种子、外部数据版本和事件游标的快照。
- 已完成：13 种 runtime 行动的前置条件、资源成本、确定性成功概率、结构化失败和直接效果结算；金钱成本进入可对账的系统服务账户。
- 已完成：延迟效果队列、逐项事务回滚、到期 tick 结算和来源事件追踪。
- 待完成：快照恢复和隔离分叉、多尺度更新调度。

### 0.1 环境配置与版本

空间、制度、资源、角色和经济条件应由配置或模板生成，而不是散落在核心代码中。

至少支持：

- 校园规模、空间布局、距离和容量。
- 学校类型、学期制度、课程密度和门禁规则。
- Agent 人口结构、角色比例和初始禀赋。
- 资源丰富程度、经济水平和价格基线。
- 组织、课程、社团、岗位和活动生成。
- 城市、文化、政策和外部经济背景。
- 环境模板复制、修改、版本管理和分享。
- 随机生成与真实数据初始化两种模式。

验收标准：

- 研究者无需修改核心代码即可生成不同校园。
- 同一实验可在不同参数环境中重复运行。
- 环境配置可导出、导入、比较和复现。
- 每次运行可追溯到完整配置版本。

### 0.2 统一因果执行模型

所有行动应进入统一的“状态—感知—行动—结果”模型：

```text
环境状态
→ Agent 可感知信息
→ 当前可行动作
→ 行动前置条件
→ 时间与资源消耗
→ 成功概率
→ 直接结果
→ 延迟结果与副作用
→ 世界状态更新
```

每种行动至少应定义：

```text
action_type
actor
target
preconditions
required_resources
duration
location
visibility
success_probability
direct_effects
delayed_effects
side_effects
failure_reasons
rule_version
```

验收标准：

- 行动失败、延迟和替代选择有结构化原因。
- 同一行动在不同状态、地点和 Agent 上成本不同。
- 直接后果和延迟后果都可追踪到来源事件。
- LLM 负责选择或解释，规则层负责验证和结算。

### 0.3 世界快照、事件谱系与分叉

- 快照包含客观状态、配置版本、随机种子和外部数据版本。
- 每个状态变化都能追溯到行动、规则、干预或外部事件。
- 可从同一快照创建多个世界分支。
- 分支之间可只改变一个参数或干预。

验收标准：

- 同一快照和随机种子可重放关键过程。
- 研究者能区分自然演化、模型决策和人工干预。
- 世界分叉不会共享可变状态或相互污染。

### 0.4 多尺度更新机制

明确每类变量的更新频率、聚合方式和延迟：

- 个体身体与位置。
- 关系与群体互动。
- 组织预算和制度决策。
- 校园宏观指标。
- 外部市场、政策和社会变化。

验收标准：

- 宏观制度不会每个 tick 随机变化。
- 长期变量不会被单次噪声立即改写。
- 聚合指标来源于底层事件，而不是独立生成。

## 阶段 1：个体在环境中生活

### 1.1 空间真实约束

- 容量上限与实际占用。
- 排队、等待和满员拒绝。
- 空间距离、移动时间和通行成本。
- 门禁、楼层、入口、开放时间和临时维护。
- 座位、设备、窗口、打印机和实验室名额。
- 噪音、光照、温度、天气暴露和网络状态。

验收标准：

- 空间能够拒绝、延迟或改变行动。
- 路径、等待、迟到和换地点有明确环境原因。
- 空间约束能引发聚集、迁移、关系接触和新闻事件。

### 1.2 时间制度

- 课表、上下课、考试周和截止日期。
- 饭点、门禁、闭馆和校务窗口。
- 社团、讲座、值班、会议和临时通知。
- 工作日、周末、学期、假期和毕业季。

验收标准：

- Agent 在制度时间中做选择，而不是随机访问地点。
- 晚到、请假、错峰、赶路和等待自然出现。
- 同一空间在不同时段承担不同社会功能。

### 1.3 身体、认知与情绪状态

- 饥饿、疲劳、睡眠、健康和体力。
- 压力、情绪、注意力和社交能量。
- 吃饭、休息、睡眠、运动、独处和倾诉等恢复机制。
- 睡眠不足、压力和冲突的累积后果。

验收标准：

- 行动有成本，恢复需要时间。
- 身体状态能迫使 Agent 改变计划。
- 长期状态积累能进入生命历程和后续决策。

### 1.4 有限可观测性

有限可观测性必须在传播和社会推理之前建立：

- Agent 只能知道自己看见、听见、被告知或推断的事。
- 信息具有来源、时间、置信度、范围和误差。
- 观察者的关注不等于获得全部内部状态。
- 同一事件可以形成多个相互冲突的主观解释。

验收标准：

- 决策上下文不直接读取完整数据库真相。
- 研究导出能区分事实、观察、信念和推断。
- 未接触消息的 Agent 不会提前对消息作出反应。

### 1.5 个体能力与异质性

- 知识、专业技能、沟通和身体能力。
- 时间管理、信息辨别和数字工具能力。
- 社会影响力、经济条件和家庭背景。
- 文化与语言背景、风险偏好和规则遵从。
- 初始资源、机会渠道和社会支持。

验收标准：

- 同一行动对不同 Agent 有不同成本和成功率。
- 经济困难、能力差异和社会资本会造成不同机会。
- 差异来自可解释变量，而不只是 LLM 文风。

## 阶段 2：经济、组织与社会运行

### 2.1 校园经济主体

至少区分以下主体：

- 个人与家庭支持：学生、教师、职员和访客。
- 生产与服务主体：食堂、商户、社团项目和校内创业团队。
- 组织主体：学院、学校部门、实验室和学生组织。
- 公共部门：学校预算、补贴、公共服务和应急储备。
- 外部部门：城市商户、就业市场、金融机构和家庭经济。

每类主体拥有账户、资产、负债、预算、收入来源、支出义务和决策规则。

### 2.2 预算约束、机会成本与跨期选择

真实经济行为首先受到预算和时间约束：

```text
可支配资源
= 期初资产
+ 收入
+ 转移支付
+ 借款
- 必要支出
- 偿债
- 储蓄
```

需要表达：

- 有限收入下的消费、学习、社交和储蓄权衡。
- 时间用于上课、兼职、休息或社交的机会成本。
- 当前消费与未来目标之间的跨期选择。
- 风险偏好、流动性不足和紧急支出。

验收标准：

- Agent 不能在余额不足时无限消费。
- 放弃某项行动会释放时间或资金给其他行动。
- 短期选择会影响长期资产、健康、技能和机会。

### 2.3 收入、劳动与分配

- 工资、兼职、奖学金、助学金和家庭支持。
- 学费、住宿、餐饮、交通和学习成本。
- 岗位需求、技能匹配、劳动时间和工资差异。
- 组织预算、项目经费和报销。
- 税费、补贴、罚款和公共转移支付。

验收标准：

- 每笔收入有支付方，每笔支出有接收方或明确销毁机制。
- 劳动报酬与时间、技能、岗位和制度相关。
- 初始禀赋和持续收入差异会形成可测量的不平等。

### 2.4 商品、服务、生产与库存

- 商品和服务具有生产成本、容量、质量和交付时间。
- 商户需要采购、生产、补货并承担库存与损耗。
- 服务受人力、设备、空间和开放时间约束。
- 上游断供会传导到库存、价格和替代消费。

验收标准：

- 库存不会无来源自动恢复。
- 售出商品对应库存减少、现金流入和成本结转。
- 产能不足会导致排队、缺货、涨价或替代。
- 服务消费与商品交易使用不同的结算和容量模型。

### 2.5 供需、价格与市场摩擦

价格不能只是由 Agent 或 LLM 任意填写，应由可配置机制形成：

- 需求由需要、偏好、边际效用、预算、预期和社会影响共同决定。
- 供给由边际成本、固定成本、库存、产能和预期需求共同决定。
- 价格弹性、替代品和互补品。
- 固定价、竞价、议价、配给和动态定价。
- 搜索成本、交易成本和信息不对称。
- 品牌、信誉、质量预期和关系价格。
- 合同、预订、违约、退款和售后。

不要求所有市场都使用同一种“经济规律”。食堂套餐可以固定定价和配给，社团二手交易可以议价，稀缺实验资源可以按审批或排队分配。

验收标准：

- 价格变化可解释为供需、成本、规则或冲击结果。
- Agent 会因价格、收入和替代品改变需求。
- 市场不出清时会出现缺货、排队、积压或配给。
- 同一机制在相同状态和随机种子下可复现。

### 2.6 储蓄、信用、风险与违约

- 储蓄目标、应急资金和消费信贷。
- 借贷、利息、期限、抵押或担保。
- 信用记录、违约、延期和关系借款。
- 不确定收入、意外支出和风险分担。

验收标准：

- 借款产生资产和负债两侧记录。
- 利息和违约会改变未来预算与机会。
- 信用机制不会凭空创造不可追踪的资源。
- 经济冲击对高负债和低储蓄 Agent 影响更大。

### 2.7 公共品、外部性与经济政策

- 图书馆、网络、安保和公共空间等公共服务。
- 拥挤、噪音、污染、声誉和知识扩散等外部性。
- 补贴、限价、奖学金、配额、收费和公共投资。
- 效率、公平、可达性和财政约束之间的权衡。

验收标准：

- 政策成本进入明确预算。
- 政策改变激励，而不是直接指定所有 Agent 的选择。
- 同一政策对不同收入、角色和空间群体产生不同后果。
- 可比较政策实施前后的福利、分配和行为指标。

### 2.8 经济核算与宏观指标

所有经济变化都应进入统一账本：

- 资金流采用可追溯的双边或复式记录，商品流和服务流保留对应结算。
- 账户余额、资产、负债和净值。
- 收入、消费、储蓄和投资。
- 价格指数、缺货率、交易量和周转率。
- 名义价格、实际购买力、通胀和外部资金流入。
- 收入与财富分布、基尼系数或分位差。
- 公共预算、补贴覆盖率和资源可达性。

核心约束：

```text
除明确的发行、销毁、折旧和外部流入外，
世界内部的资金与资源变化必须能够对账。
```

验收标准：

- 任意时点都能解释余额和库存如何形成。
- 账本不平衡会触发测试失败或异常事件。
- 宏观指标由交易与账户聚合产生。
- 日报可以报道经济现象，但不能反向制造账本事实。

### 2.9 组织与集体行动

组织不是成员行动的简单汇总。学院、班级、社团、实验室和部门应拥有：

- 目标、预算、资源和规则。
- 成员、职位、权力结构和决策流程。
- 组织记忆、声誉和对外关系。
- 决策延迟、内部冲突和联盟。

验收标准：

- 组织可作为主体发起事件、签订承诺和分配资源。
- 个体目标与组织目标可以冲突。
- 组织身份会影响信息、机会、责任和经济收益。

### 2.10 社会传播、制度与权力

- 八卦、谣言、误读、失真和澄清。
- 权威公告、社交媒体、群聊和线下传播。
- 请假、审批、处罚、奖励、申诉和绕行。
- 正式权力、非正式影响力和制度信任。

验收标准：

- 传播路径、暴露对象和信息变形可追踪。
- 同一规则对不同角色有不同可行性和后果。
- 信息和权力可以影响价格、机会、关系和组织决策。

## 阶段 3：适应、开放世界与长期演化

### 3.1 学习与策略变化

区分：

```text
短期状态变化：疲劳、情绪和注意力
中期策略变化：回避拥挤、改变消费或合作对象
长期能力变化：技能、习惯、信誉和制度预期
```

验收标准：

- Agent 会根据成功、失败和他人反馈调整策略。
- 技能可随实践增长或长期不用而衰退。
- 学习结果会影响成本、成功率和目标优先级。

### 3.2 人口与成员流动

- 新生、毕业、转专业、休学和退学。
- 交换生、教师调动和岗位变化。
- 社团招新、退出、宿舍调整和组织换届。
- 家庭支持、城市迁移和外部机会变化。

验收标准：

- 长期世界的人口结构不会永久固定。
- 人口变化会影响资源需求、组织记忆和关系网络。
- 离开世界的 Agent 保留可审计历史，但不继续行动。

### 3.3 真实世界数据接入

可接入：

- 新闻、政策、天气和城市交通。
- 就业市场、工资水平和商品价格。
- 校园公告、活动和公共卫生信息。
- 行业变化和社交媒体趋势。

每条外部数据至少记录：

```text
source
collected_at
occurred_at
credibility
geographic_scope
affected_population
expires_at
review_state
```

正确链路是：

```text
真实数据进入世界
→ 转化为外部事件
→ 通过媒体、组织或关系传播
→ Agent 分别感知
→ 形成不同理解和行动
```

### 3.4 异常、冲击与恢复

- 暴雨、停电、故障、断供和安全事件。
- 考试延期、公共卫生和城市事件。
- 就业、价格、收入和政策冲击。
- 恢复资源、应急决策和次生影响。

验收标准：

- 冲击改变可行动作、成本、供需和组织决策。
- 系统记录冲击来源、范围、持续时间和恢复过程。
- 同一冲击对不同群体产生异质后果。

### 3.5 长期轨迹与路径依赖

- 习惯、信誉、社会位置和目标转变。
- 高光、失败、关系修复和经济积累。
- 课程、项目、就业、社团和毕业阶段。
- 初始禀赋、早期事件与后续机会之间的路径依赖。

验收标准：

- 生命历程呈现阶段、转折、原因和后果。
- 长期目标被环境、关系、制度和经济条件持续塑形。
- Agent 不会每天重置人格、策略和资源历史。

## 阶段 4：研究、校准与治理

### 4.1 校准与有效性验证

可使用：

- 客流、课表、空间使用和食堂高峰数据。
- 价格、消费、岗位、奖助学金和预算数据。
- 问卷、访谈、社交网络统计和作息研究。
- 真实事件案例与领域专家评审。

建立三类指标：

- 微观有效性：行动数量、时间分配、消费结构、社交频率和计划完成率。
- 宏观有效性：客流曲线、价格分布、交易量、网络密度、传播速度和资源分配。
- 机制有效性：现象是否由正确机制产生，而不是由 LLM 直接编排。

验收标准：

- 每个重要指标具有目标范围、数据来源和误差说明。
- 校准数据与验证数据分离。
- 规则改变后自动运行回归和敏感性分析。

### 4.2 实验与反事实控制

- 对照组、实验组和随机分组。
- 单变量、多因素和剂量实验。
- 干预开始时间、结束时间、对象和实际暴露。
- A/B 世界、重复运行和反事实分叉。

验收标准：

- 可从相同快照和随机种子分叉世界。
- 可证明两个世界除目标变量外保持一致。
- 记录 Agent 是否真正接触干预。
- 支持多次运行后的统计比较，而非只展示一个故事。

### 4.3 敏感性、稳健性与失败分析

- 参数扰动和随机种子变化。
- LLM 可用与不可用模式对照。
- 极端值、边界条件和压力测试。
- 死锁、数据缺失、规则冲突和账本不平衡。

验收标准：

- 关键结论不会只在单一随机种子下成立。
- 失败运行被保留并分类，不被静默删除。
- 研究报告明确机制假设和不确定性。

### 4.4 伦理、安全与隐私

- 真实人物、敏感属性和心理状态的使用边界。
- 真实校园或组织复刻的授权。
- Prompt、行为日志和外部数据脱敏。
- 研究机构之间的数据隔离和访问控制。
- 干预实验伦理审查和高风险用途限制。
- 禁止将模拟推断直接用于现实个体的重要决策。

验收标准：

- 环境模板标注数据授权、敏感等级和允许用途。
- 导出数据遵循最小必要原则。
- 高风险实验需要显式审批和审计记录。

## 对反馈的采纳与优先级调整

本次路线图接受了反馈中的主要判断，并作出以下结构变化：

- 将环境生成、统一因果执行、快照分叉和多尺度更新前移为阶段 0。
- 将有限可观测性从后期能力前移到阶段 1，避免决策系统继续依赖全局真相。
- 将个体异质性从人物描述升级为成本、能力、机会和成功率差异。
- 将资源稀缺扩展为能够核算的经济闭环，而不是继续增加零散资源字段。
- 将组织设为独立行动主体，拥有预算、规则、记忆和决策延迟。
- 将学习、人口流动、外部世界、校准、反事实和伦理纳入正式阶段。
- 将“能否出现某种现象”的验收升级为微观、宏观和机制有效性验证。

路线图没有把所有能力都提前到第一阶段。经济、传播和组织机制仍依赖阶段 0 的因果与状态底座；复杂金融、外部市场和研究治理也不应阻塞最小校园生活闭环。

## 推荐实施顺序

```text
阶段 0：环境配置 + 因果执行 + 状态分层 + 快照分叉 + 多尺度时钟
阶段 1：空间时间 + 身体认知 + 有限可观测性 + 个体异质性
阶段 2：经济闭环 + 组织行动 + 社会传播 + 制度权力
阶段 3：学习适应 + 人口流动 + 外部数据 + 冲击恢复 + 长期轨迹
阶段 4：校准验证 + 反事实实验 + 稳健性 + 研究治理
```

阶段 0 防止后续功能继续堆成互不相连的字段。

阶段 1 让 Agent 真正在有限信息和真实约束中生活。

阶段 2 让资源、价格、组织、关系和权力形成社会结构。

阶段 3 让世界持续变化，并与外部社会发生联系。

阶段 4 让系统从“能够产生故事”升级为“能够支持可信研究”。

## 经济系统的最小可行闭环

经济系统不应一次实现全部金融和市场机制。建议先完成一个能够对账的最小闭环：

```text
1. 统一账户与交易账本
2. 商品/服务目录和库存来源
3. 固定周期收入与必要支出
4. 商户采购、生产、补货和成本
5. 可配置价格规则与缺货/配给
6. Agent 预算约束、替代选择和储蓄
7. 公共预算、补贴和收费
8. 资金、库存和宏观指标对账
```

第一版先验证“钱从哪里来、到哪里去，商品如何产生和消失，价格为什么变化”。在账本闭环稳定后，再加入劳动市场、信用、合同、外部市场和复杂政策。

## 防止伪真实感

以下现象不能单独证明系统真实：

- Agent 会谈论钱，但余额不受影响。
- 商户会涨价，但没有成本或需求变化。
- 日报报道缺货，但库存没有减少。
- 所有人同时知道同一条消息。
- 组织有名称，但没有预算、规则和决策过程。
- 出现宏观曲线，但不能追溯到底层事件。
- LLM 给出合理解释，但相同状态无法复现。

每项“真实感”能力都必须同时具备：

```text
结构化状态
+ 可执行规则
+ 可追踪事件
+ 对后续行动的影响
+ 可校准指标
```
